# Personal Tools

A collection of small browser-based apps and interactive tools, organized behind a single front page.

## Structure

- `/` — tool launcher / home page
- `/orbit/` — orbit explorer (placeholder)
- `/vector-field/` — vector field explorer (placeholder)

The site is intentionally built as portable static web content so it can run on GitHub Pages now and move to a personal domain later without changing the app structure.

## Hosting

Designed for GitHub Pages using the repository root as the publishing source.
